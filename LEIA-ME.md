## Como tirar os prints
1. Executem o sistema localmente.
2. Abram cada tela no navegador.
3. Ajustem o zoom para que a tela fique legível.
4. Façam a captura com `Win + Shift + S`.
5. Salvem a imagem com o nome sugerido e adicionem aqui no GitHub.

**Importante:** incluam somente telas que realmente foram implementadas. Se alguma tela ainda não estiver pronta, não criem um print que dê a entender que ela funciona.
